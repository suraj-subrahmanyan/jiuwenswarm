# Superseded source material

Everything in this directory is **superseded source material** from analysis Revisions 1–4. It is
preserved for provenance and detailed evidence, but it is **not required reading**: the seven
primary documents one level up contain everything a reviewer needs to understand and judge the
recommendation.

The numbered documents here overlap heavily and reflect the analysis as it evolved, including
positions that were later corrected (each correction is recorded in `15-correction-log.md`). Where
these documents and the primary set disagree, **the primary set is authoritative**.

Still-current machine-readable artifacts live in `../traceability/` and are linked from the
primary documents directly.
